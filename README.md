# Isaac Bot — автопилот для The Binding of Isaac: Repentance+

Lua-мод (без сторонних загрузчиков) для Repentance+ v1.9.7.17.J460. Только для одиночной офлайн-игры.
Бот сам проходит забег любым персонажем: зачищает комнаты, уклоняется, подбирает предметы и
расходники, ходит по карте этажа и выбирает выход к нужной концовке.

## Установка
1. В игре включены моды (`EnableMods=1` в `options.ini`).
2. Папка `mod` должна лежать в `<игра>\mods\isaac_bot` (копия или символическая ссылка).
3. Начните обычный забег — бот включается сам. В консоли можно `restart <номер персонажа>`.

## Управление
- `F9` — бот вкл/выкл (сразу возвращает управление игроку).
- `F8` — меню бота (мышью). Пока меню открыто, игра не получает ввод, а HUD игры скрыт.
- `F7` — следующий пресет (если есть несохранённые изменения, нужно нажать ещё раз).
- Меню:
  - сверху — пресеты: выбор из списка, «Сохранить», «Сохранить как» (своё название),
    «…» — переименовать, сбросить изменения, загружать при запуске игры, удалить.
    Встроенные пресеты: Стандарт, Спидран до Мамы, Азазель до Агнца;
  - слева — состояние забега, цель (Мама / Сердце / Айзек / Сатана / ??? / Агнец / Авто),
    персонаж (тот же / по кругу / случайно / конкретный), переключатели поведения;
  - справа — приоритеты и исключения картинками предметов (приоритеты можно перетаскивать,
    правый клик или крестик убирает), под ними каталог из 721 предмета с поиском по номеру или
    названию (русская раскладка — кнопка RU/EN или `Tab`), фильтры, кнопки `+`/`−` в строке;
    `↑/↓`/`PgUp`/`PgDn` выбирают строку, `Enter` вносит её в приоритеты, `Shift+Enter` — в исключения;
  - у каждой настройки маленький «?» — клик показывает, для чего она нужна.
- Внизу экрана строка состояния: что бот делает сейчас.

## Что умеет
- Сетка комнаты, поиск пути с обходом ям/камней, подрыв камней бомбой, нажатие кнопок-плит.
- Симуляция снарядов, тел и лазеров на ~0.5 с вперёд и выбор безопасного направления.
- Бой с учётом типа оружия (слёзы, Brimstone, Tech, Mom's Knife, зарядка), активные предметы.
- Оценка предметов и расходников, цены в магазине, ловушки (сердца для Lost/Keeper и т. п.).
- Граф комнат этажа: сокровищница/магазин/библиотека → босс → люк или луч света по цели;
  Polaroid/Negative учитываются после Mom's Heart.
- Статистика забегов, авторестарт, смена персонажа по кругу.

## Ограничения (честно)
Не используются пилюли и карты, не ищутся секретные комнаты и лазы, нет альтернативного пути
(Downpour/Mines, Mother/Beast), нет крафта T.Cain и особого управления T.Forgotten и Jacob & Esau.
Бот — эвристика, а не гарантированное прохождение: он может погибнуть, особенно за хрупких
персонажей и на поздних этажах.

## Для разработки
- `python tools/bridge.py "luamod isaac_bot"` — перезагрузить мод в запущенной игре;
  `"restart 7"` — новый забег за Azazel; `"bot goal lamb"`, `"bot status"` — настройки бота.
- `python tools/runlog.py` — отчёт по забегам из `log.txt` (этажи, смерти, урон, предметы, застревания).
- `python -I tools/verify_lua.py <file.lua>` — проверка синтаксиса и неизвестных глобалов.
- `python tools/night.py --until 08:00 --char 0` — ночной прогон: бэкап сохранений
  (`isaac-night-steam`/`isaac-night-mygames`, последние 7), сторож снимает паузу, перезапускает
  застрявший забег, а при молчании лога убивает игру по PID и запускает заново через Steam
  (до 5 раз). Все события копируются в `runs/night-*.jsonl`.
- `python tools/nightreport.py` — утренняя сводка `runs/report-*.md`: % побед в чистых забегах на
  Сложной, средний достигнутый этаж и доля дошедших до 3/5/8 этажа, смерти по этажам и причинам,
  застревания, действия сторожа.
- `python tools/bench.py [--cap 5] [--n 10] [--tag метка]` — стенд: 30 одних и тех же сидов
  (`tools/bench_seeds.txt`) за Исаака на Сложной, чтобы сравнивать версии бота. Работает в фоне и
  не трогает окно игры, пока вы за компьютером. Сводка `runs/bench-*.md` с номером коммита и
  разницей по каждому сиду с прошлым стендом. Сидовые забеги в победы не засчитываются.
- `python tools/deathview.py [файл.jsonl|log.txt] [--list] [--death N]` — разбор смертей: мод пишет
  последние 3 секунды перед смертельным ударом (бот, враги, снаряды, лазеры, куда хотел и куда пошёл);
  картинка комнаты `runs/deaths/*.png` и покадровая хронология последней секунды.
- `python tools/progress.py` — диаграммы прогресса по всем сессиям и стендам: средний этаж и доля
  дошедших до 3/5/8-го, каждый забег со скользящим средним, удары и застревания на 100 комнат, где и
  от чего бот гибнет, стенд по сидам. Пишет `runs/progress.png` и `runs/progress.md`.
- Журнал разработки и проверенные факты об API — `MODLOG.md`.

Мод не меняет файлы игры, не обходит защиту и не работает в онлайне. Перед тестами сделайте
резервную копию сохранений.
